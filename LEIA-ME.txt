1) Copie os ficheiros novos/substituidos:
      unzip -o ~/Downloads/loja-seguranca-v2.zip -d /tmp/seg2
      cp -r /tmp/seg2/src/. src/
      cp /tmp/seg2/prisma/schema.prisma prisma/schema.prisma
      cp /tmp/seg2/aplicar-seguranca.mjs .
2) Altere os ficheiros com design (so as linhas de seguranca):
      node aplicar-seguranca.mjs
3) Migracao:
      npx prisma migrate dev --name seguranca
4) rm -rf .next && npm run dev
